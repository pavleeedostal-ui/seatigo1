# Club crests

Generated by `npm run sync:crests` (see `scripts/sync-club-crests.ts`). Do not
edit by hand — the sync script rewrites this directory and
`src/lib/football/club-crest-manifest.json` together.

## Source

Crests are fetched from the crest CDN of the configured football data
provider, football-data.org (`https://crests.football-data.org/<teamId>.svg|png`),
which distributes them to API consumers for identifying the teams its fixture
data covers. Seatigo stores them locally so pages are not hotlinking the
provider on every view.

Clubs that provider does not cover carry an explicit `crestUrl` in
`src/lib/football/club-logos.ts`, pointing at the competition's own asset
host — LALIGA's club shields, Ligue 1's, or UEFA's team artwork
(`https://img.uefa.com/imgml/TP/teams/logos/700x700/<teamId>.png`) for the
Champions League clubs that play in no league Seatigo covers. Oversized
sources are downscaled on sync, so a 700px original is stored at the size it
actually renders.

## Rights

Club crests are the trademarks of their respective clubs. They are used here
only to identify the club whose fixtures and ticket offers are being listed —
nominative use — and carry no endorsement by, or affiliation with, any club.
Seatigo claims no ownership of them.

Before going to production, confirm this use with the provider's terms and, if
a club objects, remove that club's entry from the manifest: it will fall back
to the neutral mark automatically, with no code change.

A crest is never substituted with another club's badge. Clubs without an
available crest render the neutral fallback in `ClubLogo`.
