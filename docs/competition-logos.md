# Competition logos

Generated by `npm run sync:logos` (see `scripts/sync-competition-logos.ts`).
Do not edit by hand — the sync script rewrites `public/images/competitions/`
and `src/lib/football/competition-logo-manifest.json` together.

## Source

Logos are fetched from the emblem CDN of the configured football data
provider, football-data.org (`https://crests.football-data.org/<code>.svg|png`),
which distributes them to API consumers for identifying the competitions its
fixture data covers. Seatigo stores them locally so pages are not hotlinking
the provider on every view.

Where the provider's emblem is a superseded sponsor lockup, the registry
entry carries an explicit `logoUrl` pointing at the organiser's own current
asset, and the sync script prefers it. That applies to LALIGA EA SPORTS,
Serie A Enilive, and the UEFA Champions League — whose navy lockup comes
from UEFA's brand host rather than the provider's older flat black starball.
These are used as published; no imitation of a competition mark is ever
generated.

## Coverage

The registry in `src/lib/football/competition-logos.ts` lists every
competition Seatigo knows how to brand, including ones it does not list
fixtures for yet — so a competition is branded the moment the football
provider starts returning it, with no code change.

The provider currently serves emblems for 11 of the 23 registry entries.
These have **no** emblem available and render the neutral trophy fallback
beside their full name:

    conference-league   fa-cup            efl-cup
    copa-del-rey        dfb-pokal         eredivisie
    belgian-pro-league  czech-first-league
    austrian-bundesliga swiss-super-league
    ekstraklasa         super-lig

To light one up, drop a licensed file into `public/images/competitions/`
named after the slug and add it to the manifest. No code change is needed.

Note that some provider assets carry a dated sponsor lockup (`la-liga.png` is
the LaLiga Santander mark; `championship.png` is the Sky Bet Championship
mark). Replace those files if you obtain current unsponsored artwork.

## Rights

Competition logos are the trademarks of their respective organisers. They are
used here only to identify the competition whose fixtures and ticket offers
are being listed — nominative use — and carry no endorsement by, or
affiliation with, any league or governing body. Seatigo claims no ownership
of them.

Before going to production, confirm this use against the provider's terms. If
an organiser objects, remove that entry from the manifest: it falls back to
the neutral mark automatically.

A logo is never substituted with another competition's — see the duplicate
alias guard in `competition-logos.ts`.
